# Portfolio

Hey! 👋  
This is my personal portfolio site built with React, Vite, and Tailwind CSS.

## What’s inside
- A simple landing page
- Project highlights
- About me section
- Contact links

## Run it locally
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start dev server:
   ```bash
   npm run dev
   ```

## Build for production
```bash
npm run build
```

## Lint
```bash
npm run lint
```

That’s it — feel free to explore or use it as inspiration.
